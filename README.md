# E-Commerce Selenium Automation Framework

A robust test automation framework built for E-commerce application testing using Selenium WebDriver, Java, TestNG and Maven.

## Tech Stack
- Language: Java 11
- Automation Tool: Selenium WebDriver 4.15.0
- Test Framework: TestNG 7.8.0
- Build Tool: Maven
- Driver Management: WebDriverManager
- Browser: Chrome

## Test Scenarios Covered
1. LoginTest
   - Valid login
   - Invalid login with error validation

2. SearchTest
   - Product search functionality
   - Search results validation

## How to Run Tests
mvn clean test

## Key Features
- WebDriverManager for auto driver handling
- TestNG annotations & assertions
- Maven build management
- Ready for Page Object Model
